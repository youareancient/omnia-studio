# YouTube Voiceover Studio Online

An AI-powered voiceover studio for YouTube content creation using edge-tts and web interface.

## Online Deployment & Editing Options

### 1. Hugging Face Spaces (Recommended for hosting & online editing)
1. Go to [huggingface.co/new-space](https://huggingface.co/new-space)
2. Select **Docker** as the Space SDK (Blank).
3. Upload all project files or push via git.
4. Your app will automatically build and run online at port `7860`.

### 2. GitHub Codespaces (Full VS Code in Browser)
1. Push this project to a GitHub repository.
2. Click **Code** -> **Codespaces** -> **Create codespace on main**.
3. Edit code right inside your web browser with terminal support.
